# TÜRKİYE RP

TÜRKİYE RP topluluğu için mobil uyumlu, tek sayfalık tanıtım ve duyuru sitesi.

## Cloudflare Pages ile yayınlama

1. Cloudflare Dashboard → **Workers & Pages** → **Create** → **Pages** → **Connect to Git**.
2. `7hmbz725vy-eng/turkiye-rp` deposunu seç.
3. Framework preset: **None**.
4. Build command: boş bırak.
5. Build output directory: `/`.
6. **Deploy** seçeneğine bas.

## Yayın öncesi güncellenecekler

- Topluluk/Discord davet bağlantısı ve iletişim adresi.
- Kesin etkinlik tarihleri ve saatleri.
- Gerçek duyuru ve başvuru bağlantıları.

Site, Roblox veya Emergency Hamburg ile resmî ortaklık iddiasında bulunmaz.
